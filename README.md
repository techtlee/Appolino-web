# Appolino website

Marketing site for Appolino, built with Vite 5, React 18 and TypeScript. The product demos
in the hero window (Validate, Ask, Pipelines, Jobs, Access) run in the browser with example data.

## Develop

```sh
npm install
npm run dev        # http://localhost:5174
```

## Build

```sh
npm run build      # type-checks, then writes dist/
npm run preview    # serves dist/ locally
```

All figures on the site are examples, not customer data.
